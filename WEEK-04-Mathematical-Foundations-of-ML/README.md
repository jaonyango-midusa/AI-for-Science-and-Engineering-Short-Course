# WEEK 4 | Mathematical Foundations of Machine Learning

## Lesson Outline
- Why Mathematics Matters in Machine Learning
- Scalars, Vectors, and Matrices
- Representing datasets mathematically
- Features and targets as mathematical quantities
- Descriptive Statistics
    Mean, median and mode
    Range, variance and standard deviation
    Understanding distributions
- Relationships Between Variables
    Covariance
    Correlation
    Correlation vs causation
- Probability and Uncertainty
    Basic probability concepts
    Conditional probability
    Understanding uncertainty in data and predictions
- Functions and Mathematical Models
    Inputs and outputs
    Relationships between variables
    Parameters
- Error and Loss
    Actual vs predicted values
    Measuring error
    The idea of a loss/cost function
- Optimization: How a Model Learns
    What does it mean to “fit” a model?
    Minimizing error
    Intuition behind gradient descent

## Expected Learning Outcomes
By the end of this lesson, participants should be able to:
- Explain the role of mathematics and statistics in machine learning.
- Represent data using basic mathematical structures such as vectors and matrices.
- Use basic descriptive statistics to summarize and understand data.
- Explain relationships between variables using covariance and correlation.
- Explain the role of probability and uncertainty in machine learning.
- Describe the relationship between inputs, model parameters and outputs.
- Explain the concepts of prediction error, loss and optimization.
- Describe, intuitively, how a machine learning model learns from data.
