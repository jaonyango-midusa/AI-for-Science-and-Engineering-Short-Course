# Week 10 | Model Evaluation, Deployment & Monitoring

## Lesson Outline
In this lesson, we will talk about;
- Revisiting Model Evaluation
- Generalization & Model Reliability
- Model Interpretation & Explainability
- From Model to Deployment
- Model Monitoring
- Responsible Deployment

## Expected Learning Outcomes
By the end of the lesson, participants should be able to:
- Select and interpret appropriate model evaluation metrics.
- Explain generalization, overfitting, data leakage, and model robustness.
- Interpret model predictions using basic explainability techniques.
- Explain what model deployment means in a practical ML workflow.
- Save and use a trained model to make predictions on new data.
- Explain why deployed ML models require monitoring.
- Identify data drift, performance degradation, and situations requiring model retraining.
- Discuss responsible considerations when deploying ML systems.

## Week 10 Assignment | Evaluating and Preparing Your ML Model for Use
Using a machine learning model developed for your project:
- Evaluate the model on unseen/test data using appropriate performance metrics.
- Compare the training and test performance and comment on whether there is evidence of overfitting or underfitting.
- Use feature importance or SHAP to investigate what is influencing the model's predictions.
- Interpret the results: do the important features and model behaviour make sense based on your scientific/engineering knowledge?
- Save the trained model and demonstrate that it can be loaded and used to make a prediction on new data.
- Briefly describe:
  1. How the model could eventually be deployed or used in practice.
  2. What would need to be monitored after deployment.
  3. One limitation or risk that should be considered.
- Save the notebook in your course-project GitHub repository and submit the notebook link on Google Classroom.
