# Week 6 | Unsupervised Machine Learning Models
## Lesson Outline 
In this lesson, we will talk about:
- Introduction to Unsupervised Learning
- Clustering
- Dimensionality Reduction
- Anomaly Detection
- Building Unsupervised Models in Python
- Evaluating Unsupervised Learning Results
- Applications in Science and Engineering

## Expected Learning Outcomes
By the end of this lesson, participants should be able to:
- Explain the principles of unsupervised machine learning.
- Distinguish between supervised and unsupervised learning.
- Explain the purposes of clustering, dimensionality reduction, and anomaly detection.
- Apply basic unsupervised learning techniques using Python.
- Visualize and interpret patterns identified by an unsupervised model.
- Explain the role of feature scaling in unsupervised learning.
- Evaluate unsupervised learning results using appropriate methods and domain knowledge.
- Determine whether unsupervised learning could be useful for their project.

## Week 6 Assignment | Discovering Patterns in Data
Using your project dataset where suitable, or another appropriate dataset:
1. Select the numerical features you want to investigate.
2. Prepare the selected features for clustering, including scaling the data where necessary.
3. Apply K-Means clustering to the data.
4. Explore different numbers of clusters and select an appropriate number.
5. Visualize the clusters using an appropriate plot.
6. Describe the characteristics of the groups identified by the model.
7. In a short Markdown discussion, explain whether the clusters are meaningful in the context of the problem and what they might represent.
8. Save the completed notebook in your course-project GitHub repository and submit the notebook link on Google Classroom.
