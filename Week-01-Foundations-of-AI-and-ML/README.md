# Week 1 | Foundations of AI & Machine Learning

## Lesson Outline
In this lesson, we will talk about:
- What is artificial intelligence?
- A Brief History and Evolution of AI  
- AI, Machine Learning, and Deep Learning  
- AI vs. Traditional Programming and Automation  
- What is a machine learning model?
- Why Machine Learning?
- How Machine Learning Works
- Types of Machine Learning
- Scientific & Engineering Applications of AI/ML
- From Scientific Problem to ML Problem

## Expected Learning Outcomes
By the end of this lesson, participants should be able to:
- Define AI and describe its evolution.
- Differentiate between AI, machine learning, and deep learning.
- Distinguish AI/ML from traditional programming and automation.
- Explain what a machine learning model is and how it learns from data.
- Describe the basic machine learning process from data to prediction.
- Explain when and why machine learning is useful for scientific and engineering problems.
- Differentiate the major types of machine learning and their uses.
- Identify scientific and engineering applications of AI/ML.
- Formulate a scientific or engineering problem as a potential ML problem.
