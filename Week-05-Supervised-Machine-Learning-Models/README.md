# WEEK 5: Supervised Machine Learning Models 

## Lesson Outline
In this lesson, we will talk about:
- Introduction to Supervised Learning
- Regression and Classification
- Regression Models
- Classification Models
- Building a Supervised ML Model in Python
- Evaluating Model Performance
- Comparing Models
- Overfitting, Underfitting, and Generalization

## Expected Learning Outcomes
By the end of this lesson, participants should be able to:
- Explain the principles of supervised machine learning.
- Distinguish between regression and classification problems.
- Describe the basic principles of common supervised learning models.
- Build and train a simple supervised machine learning model using Python.
- Use a trained model to make predictions on unseen data.
- Evaluate model performance using appropriate metrics.
- Compare the performance of different supervised models.
- Explain overfitting, underfitting, and generalization.
