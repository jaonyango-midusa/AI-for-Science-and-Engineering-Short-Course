# WEEK 5: Supervised Machine Learning Models 
In this lesson, we will talk about:
Introduction to Supervised Learning
  - What makes learning “supervised”?
  - Features (X) and targets (y)
  - Training from labelled examples
Regression and Classification
  - Continuous vs categorical outputs
  - Recognising regression and classification problems
Regression Models
  - Linear Regression
  - Decision Tree Regression
  - Random Forest Regression
Classification Models
  - Logistic Regression
  - Decision Tree Classification
  - Random Forest Classification
  - Support Vector Machines
Building a Supervised ML Model in Python
  - Selecting features and target
  - Splitting the dataset
  - Creating the model
  - Fitting/training
  - Making predictions
Evaluating Model Performance
  - Regression: MAE, MSE/RMSE and R²
  - Classification: Accuracy, Precision, Recall and F1-score
  - Confusion matrix
Comparing Models
  - Why different models produce different results
  - Choosing an appropriate model
  - Why the highest score is not always the whole story
Overfitting, Underfitting and Generalization
  - Performance on training vs unseen data
  - Recognising when a model has learned too little or too much
