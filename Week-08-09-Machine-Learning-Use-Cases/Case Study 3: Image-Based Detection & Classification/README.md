# Case Study 3: Image-Based Detection & Classification
Representative fields: Health, biology, agriculture, materials and infrastructure

Focus:
- Images as scientific data
- Detection, classification, and segmentation
- Preparing and labelling image datasets
- Training an image-based ML model
- Model outputs and their interpretation
- Accuracy, errors, and consequences of misclassification

Possible cases: medical imaging, crop disease, microscopy, structural cracks, or material defects.
