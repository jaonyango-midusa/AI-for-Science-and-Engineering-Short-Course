# Weeks 8 - 9: Machine Learning Use Cases 

## Guidelines for Presenters
Each presenter will have one hour to demonstrate how machine learning is applied to a real scientific or engineering problem. 
Please cover:
- What problem are you solving, why is it important, and how is it conventionally addressed?
- Why was machine learning appropriate for this problem?
- What data were used? What are the key inputs/features and outputs/targets?
- What model was used, what is it doing, and how was it trained and evaluated?
- Walk participants through a simplified showing the key stages of the ML workflow.
- What did you achieve, what do the results mean scientifically/technically, and what are the main limitations?

Suggested format:
20 min – Problem, data, and ML approach
25 min – Colab walkthrough
10 min – Results, interpretation, and limitations
5 min – Questions

## Expected Learning Outcomes
By the end of the lesson, participants should be able to:
- Explain how ML is applied to different scientific and engineering problems.
- Identify the problem, data, inputs, outputs, and ML approach in a real application.
- Explain the role of ML surrogate models in computational science and engineering.
- Describe how ML can support scientific and materials discovery.
- Explain how image data can be used for detection and classification.
- Critically interpret the achievements and limitations of an ML application.
