# WEEK 3: Machine Learning Workflow Design 

## Lesson Outline
This week's lesson will cover the following:
- The End-to-End Machine Learning Workflow
- Problem Definition and ML Problem Framing
- Data Sources and Dataset Discovery
- Types of Data
- AI/ML Platforms and Repositories
- Features and Targets
- Data Preparation for Machine Learning
- Training, Validation, and Test Sets
- Model Selection and Training
- Model Evaluation
- Prediction and Interpretation
- Reproducible ML Workflows

## Expected Learning Outcomes

By the end of this lesson, participants should be able to:
- Describe the main stages of an end-to-end machine learning workflow.
- Formulate a scientific or engineering problem as a machine learning problem.
- Identify potential data sources for a machine learning problem.
- Navigate common AI/ML platforms and repositories, including Kaggle, Zindi, and Hugging Face, etc.
- Identify features and targets relevant to a machine learning problem.
- Explain the purpose of training, validation, and test datasets.
- Describe the basic processes of model training, evaluation, prediction, and interpretation.

## Week 3 Assignment | Designing Your Machine Learning Workflow

Using the project problem identified in Week 1:
- Briefly restate your project problem and intended AI/ML outcome.
- Identify the information/data you would need.
- Get the dataset for your project. If you cannot find data directly related to your project, use a relevant dataset from Kaggle, Zindi, Hugging Face, or another appropriate source. 
- Import the dataset into your Colab notebook using Python and display a small portion of it.
- Identify the potential inputs (features) and output (target) for your project.
- Draw and briefly explain your proposed ML workflow.
- Save the notebook in your course-project GitHub repository and submit the notebook link on Google Classroom.
