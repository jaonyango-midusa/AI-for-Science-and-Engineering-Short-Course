# AI-for-Science-and-Engineering-Short-Course
This is a 12-week online course that provides a practical introduction to AI and machine learning workflows for scientific and engineering applications. It is intended for engineers, scientists, and researchers interested in using machine learning as a practical tool for scientific discovery, engineering analysis, predictive modeling, data-driven decision-making, etc.

## Course Information

**Duration:** 12 weeks  
**Dates:** 16 September – 2 December 2026  
**Day:** Wednesdays  
**Time:** 5:00–8:00 PM EAT  
**Mode:** Online

## Course Lessons

1. Foundations of AI & Machine Learning
2. Introduction to Python & Computing Environments
3. Machine Learning Workflow Design
4. Mathematical Foundations of Machine Learning
5. Supervised Machine Learning Models
6. Unsupervised Machine Learning Models
7. Foundations of Generative AI
8. Machine Learning Use Cases I
9. Machine Learning Use Cases II
10. Model Evaluation, Deployment & Monitoring
11. High-Performance Computing
12. Ethics & Responsible AI
