# Week 11 | High-Performance Computing for AI & Machine Learning

## Lesson Outline

In this lesson, we will cover;
- Introduction to High-Performance Computing (HPC)
- Why HPC for science, engineering, and AI/ML?
- HPC architecture and computing resources
- CPUs, GPUs, memory, storage, nodes, and clusters
- Local, cloud, and HPC computing environments
- Accessing and working in an HPC environment
- Interactive and batch computing
- Job schedulers and resource allocation
- Running AI/ML workloads on HPC
- Scaling computational and ML workflows
- Efficient use of HPC resources
- Reproducible computational workflows
- Practical HPC demonstration

## Expected Learning Outcomes
By the end of the lesson, participants should be able to:
- Explain the role of HPC in scientific computing and AI/ML.
- Identify the main components and resources of an HPC system.
- Determine when a computational or ML problem may require HPC.
- Describe how users access and work within an HPC environment.
- Explain how computational jobs are submitted and managed on a cluster.
- Describe how HPC can support larger and more computationally demanding ML workflows.
- Apply basic principles of efficient and reproducible HPC computing.
